# Pharmacy / medicine delivery app

## Regulation first (country-specific — do not guess)
Before building, the user must confirm locally:
- Licence to sell/dispense medicines online and deliver them
- Which items need a prescription, and how it must be verified (pharmacist review)
- Restricted/controlled drugs that can't be delivered
- Health-data privacy rules (e.g. GDPR, HIPAA where applicable) for prescriptions
- Delivery requirements (ID check on handover, cold chain for some items)
Recommend a pharmacy-law adviser; this skill does not replace one.

## Workflow
1. Customer searches or uploads a prescription photo.
2. Pharmacist reviews and approves / contacts customer.
3. Order prepared; temperature-sensitive items flagged.
4. Delivery with proof of delivery; optional ID check.
5. Refill reminders for repeat medicines.

## Features
Search by brand/generic/symptom category, prescription upload in the order flow (custom form fields / order notes), OTC and wellness catalog, scheduled refills, pharmacist chat (order chat), live tracking, discreet packaging option, multiple pharmacies with zones, reports.
